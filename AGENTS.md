# Codex Working Agreement (Repo-Wide)

When you make or suggest code changes in this repository:

- Always include a short **Production reasoning** section in your final response.
- In **Production reasoning**, explicitly cover:
  - What changes in production behavior (or confirm "no production impact").
  - Any required env vars / config / secrets.
  - Backward compatibility + migration/rollout notes (if relevant).
  - Risks and the simplest verification step (test/command) to run before deploy.
